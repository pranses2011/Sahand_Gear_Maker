# 📋 گزارش نهایی تحویل — نسخهٔ ۰.۲.۰ (تکمیل نقشهٔ راه)

## ۱. چه ساخته شد؟

### هندسه (۱۹ خانوادهٔ چرخ‌دنده — همهٔ نقشهٔ راه تکمیل شد)
- استوانه‌ای: خارجی مستقیم/مارپیچ/جناغی، داخلی مستقیم/مارپیچ، شانهٔ مستقیم/مارپیچ
- **۱۲ خانوادهٔ جدید این نسخه**: مخروطی مستقیم/مارپیچ (Tredgold)، کرم ZA و چرخ کرم گلوگاه‌دار، مارپیچ متقاطع، تاجی، هیپوئیدی، سیکلوئیدی (اپیسایکلوئید/هیپوسایکلوئید)، غیرمدور بیضوی (حل محیط E(e)، بور روی کانون)، فِلکسی‌پلاین هارمونیک (فنجان حالت آزاد + موج‌ساز بیضوی)، هزارخار خارجی/داخلی
- همهٔ مش‌ها آب‌بند (هر یال دقیقاً ۲ بار؛ حجم مثبت) و بازتولیدپذیر

### مونتاژ و تحلیل
- جفت‌های همهٔ خانواده‌ها + قطار مرکب + سیاره‌ای (ویلیس) + هارمونیک
- موتور سینماتیک (جفت/شانه/قطار/سیاره‌ای/هارمونیک)
- بررسی برخورد/فاصلهٔ مش، دستیار انتخاب نسبت، تحلیل هندسی (نسبت تماس/undercut/ضخامت نوک)

### نقشهٔ فنی (پروژهٔ Drawing)
- SVG فارسی RTL کامل
- PDF با فونت وزیرمتن تعبیه‌شده + شکل‌دهی حروف فارسی (اتصال‌ها/لیگاتور لام-الف/ZWNJ/bidi اعداد) — رندر تأییدشده

### ورودی/خروجی
- خروجی: STL (باینری/متنی)، OBJ+MTL، PLY، GLB، **3MF، AMF، DXF پروفیل** + نقشهٔ SVG/PDF
- ورودی مدل مرجع: STL/OBJ/PLY (هرگز پارامتریک نمی‌شود)
- خروجی دسته‌ای با گزارش موفق/ناموفق

### ابزار
- گونه‌ها (Variant) با مقایسهٔ پارامتری + فایل .sgdvars
- ذخیرهٔ خودکار + بازیابی پس از خرابی
- CLI کامل: sgm-cli (info/new/export/drawing/analyze/import)

### CI و اسکرین‌شات
- core-build-test (لینوکس): ساخت + ۱۱۶ آزمون ✅
- windows-build-screenshots (ویندوز): ساخت کامل راهکار (شامل WPF) + آزمون‌ها + publish برنامه و CLI + تولید ۱۴ اسکرین‌شات واقعی + artifacts ✅
- اسکرین‌شات‌ها: ۱۳ رندر سه‌بعدی خانواده‌ها + کپچر رابط فارسی RTL — در docs/screenshots/

## ۲. چه چیزی پشتیبانی نمی‌شود / محدود است؟ (صادقانه)

- استحکام/عمر/راندمان استاندارد-محور (AGMA/ISO): خارج از دامنه — تحلیل تنش انجام نمی‌شود.
- پوشش دقیق اپویکولوئید تاجی (Litvin) و حل‌گر تماس هیپوئید: هندسهٔ طرح‌ریزی است.
- STEP/IGES: مش به‌عنوان B-rep معرفی نمی‌شود؛ نیازمند هستهٔ CAD با مجوز.
- تلرانس‌های جداول DIN/ISO هزارخار: ابعاد «تعیین‌نشده».
- تغییرشکل‌یافتهٔ فِلکسی‌پلاین (حالت تنش): مدل نمی‌شود؛ حالت آزاد (قابل ساخت) تولید می‌شود.
- اجرای افزونهٔ کد ناشناس: ممنوع (سیاست امنیتی).

## ۳. چطور اجرا/ساخته/آزمون می‌شود؟

- هسته: `dotnet build tests/... && dotnet test tests/SahandGearMaker.Tests -c Release` — ۱۱۶/۱۱۶ سبز (لینوکس و ویندوز).
