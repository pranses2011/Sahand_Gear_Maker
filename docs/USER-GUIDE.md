# 📘 راهنمای کاربر — طراح چرخ‌دنده سهند

نسخهٔ 0.1.0 — این راهنما به زبان فارسی و برای کار با نسخهٔ ویندوزی برنامه نوشته شده است.

## شروع سریع (کمتر از دو دقیقه)

1. برنامه را باز کنید؛ در **خانه** روی «ساخت نمونه» کلیک کنید تا یک چرخ‌دندهٔ نمونه ساخته شود.
2. به تب **طراح چرخ‌دنده** بروید.
3. پارامترها را تغییر دهید (تعداد دندانه، ماژول، پهنا و…)؛ هندسه به‌طور خودکار بازسازی می‌شود.
4. با درگ ماوس روی بوم، مدل را بچرخانید؛ با Shift+درگ جابه‌جا کنید؛ با چرخ ماوس بزرگ‌نمایی کنید. راست‌کلیک حالت نمایش (سایه/سیمی/لبه‌دار) را عوض می‌کند.
5. از تب **خروجی**، فرمت (مثلاً STL باینری)، کیفیت و واحد را انتخاب و «خروجی بگیر» را بزنید.

## پارامترهای اصلی

| پارامتر | شرح | محدودهٔ معقول |
|---|---|---|
| تعداد دندانه (z) | شمار دندانه‌ها | ≥ ۵ (زیر ~۱۷ بدون اصلاح پروفیل، هشدار برش‌خوردگی می‌گیرید) |
| ماژول (m) | اندازهٔ دندانه بر حسب میلی‌متر | 0.1 تا 50 |
| زاویهٔ فشار | زاویهٔ مبنای پروفیل | تا ۴۵ درجه (متداول: ۲۰) |
| زاویهٔ مارپیچ | فقط برای مارپیچ/جناغی | تا ۶۰ درجه (متداول: ۱۵–۳۰) |
| پهنای دندانه | ضخامت در راستای محور | مثبت |
| قطر بور | سوراخ مرکزی؛ صفر = بدون سوراخ | کوچک‌تر از قطر ریشه |
| شیار خار / توپی | ویژگی‌های بدنه | اختیاری |

## ارقام محاسبه‌شده

برای چرخ‌دندهٔ استاندارد بدون اصلاح پروفیل، برنامه از روابط مرجع استفاده می‌کند: قطر گام `d = m·z`، قطر سر `dₐ = m(z+2)`، قطر ریشه `d_f = m(z−2.5)`. این اعداد «تقریبی/آزمایشی» تلقی می‌شوند مگر با مرجع استاندارد شما تطبیق داده شوند؛ برای کار حساس، مهندس مکانیک تأیید کند.

## پیام‌های اعتبارسنجی

- **خطا (قرمز):** ساخت هندسه متوقف می‌شود؛ فیلد مشکل‌دار را تصحیح کنید. پیام می‌گوید چه چیزی، چرا و چه باید کرد.
- **هشدار (کهربایی):** ادامه ممکن است ولی با آگاهی (مثلاً ریسک برش‌خوردگی).
- **اطلاع:** نکتهٔ غیرمزاحم.
- **بررسی‌نشده:** چیزی که برنامه آن را تحلیل نکرده — با «سالم/تأییدشده» اشتباه نگیرید.

## خروجی گرفتن

1. فرمت را انتخاب کنید — فقط موارد فعال واقعاً پیاده‌سازی شده‌اند.
2. کیفیت: «پیش‌نمایش» برای سرعت، «معمولی» برای تبادل، «دقیق» برای چاپ.
3. واحد را انتخاب کنید. **STL واحد درون‌فایلی ندارد**؛ اگر واحد دیگری می‌خواهید، آن را در نام فایل یا گزارش همراه ذکر کنید. GLB طبق استاندارد glTF به متر تبدیل می‌شود.
4. پس از نوشتن، برنامه فایل را **دوباره می‌خواند و اعتبارسنجی می‌کند**؛ نتیجه در گزارش می‌آید.

> همهٔ خروجی‌های این نسخه «مش مثلثی» هستند — برای چاپ سه‌بعدی و نمایش عالی‌اند، اما معادل مدل دقیق B-rep (STEP/IGES) نیستند.

## ذخیره و بازگشایی

- ذخیره با فرمت بومی `.sgdproj` انجام می‌شود؛ همهٔ پارامترها و ساختار پروژه برمی‌گردند.
- ذخیره‌سازی اتمی است: اگر هنگام ذخیره برق قطع شود، فایل قبلی سالم می‌ماند.
- فایل‌های از نسخه‌های جدیدتر بدون از دست دادن داده باز می‌شوند (فیلدهای ناشناخته حفظ می‌شوند).

## آفلاین و حریم خصوصی

- همهٔ امکانات اصلی بدون اینترنت کار می‌کنند.
- فرم بازخورد داخل برنامه است؛ از برنامهٔ ایمیل شما استفاده نمی‌شود.
- اگر سرویس ارسال پیکربندی نشده باشد، پیام شما فقط **روی همین دستگاه** ذخیره می‌شود و می‌توانید صف را پاک کنید. برنامه هرگز وانمود نمی‌کند که ایمیلی ارسال شده است.

چون در این نسخه پیاده‌سازی نشده و برنامه به‌جای ساخت مدل جعلی، آن را حذف می‌کند. ماتریس قابلیت (`docs/CAPABILITY-MATRIX.md`) وضعیت همهٔ انواع را نشان می‌دهد.

**آیا می‌توانم برای تولید واقعی از این مدل استفاده کنم؟**
مدل هندسی برای نمونه‌سازی، آموزش و چاپ مناسب است؛ اما این برنامه ابزار تحلیل تنش/عمر نیست و تأییدیهٔ ساخت نمی‌دهد.

**سوراخ‌های سبک‌سازی چرا با بور مرکزی کار نمی‌کنند؟**
محدودیت مستند این نسخه است؛ برای حفره‌ها، بور را صفر بگذارید. در نسخه‌های بعدی رفع می‌شود.
