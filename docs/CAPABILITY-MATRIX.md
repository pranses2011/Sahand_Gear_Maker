# 📊 ماتریس قابلیت — Sahand Gear Designer نسخهٔ 0.1.0

این ماتریس «وضعیت واقعی» را نشان می‌دهد؛ حضور یک گزینه در فهرست به معنی پیاده‌سازی نیست (الزام سند ۰۴، بخش ۸).

## آزمون‌ها

آزمون‌های واحد (xUnit) روی ubuntu-latest اجرا می‌شوند (CI پوشهٔ `.github/workflows/core.yml`):

- اعتبارسنجی پارامترها (خطا/هشدار/بررسی‌نشده)
- فرمول‌های مرجع (d، da، df، rb) با محاسبهٔ مستقل
- آب‌بندی مش (closed manifold) برای هر ۵ خانواده
- بازتولیدپذیری و fuzz ورودی‌های تصادفی
- جفت‌ها: فاصلهٔ محور خارجی/داخلی، جهت، سازگاری
- سیاره‌ای: قید zᵣ=zₛ+2zₚ، نسبت‌های ویلیس، قید فاز
- ماندگاری: round-trip کامل، ذخیرهٔ اتمی، حفظ دادهٔ ناشناخته
- خروجی‌ها: اعتبارسنجی پس از نوشتن، مقیاس واحد، پریست کیفیت

نتایج آخرین اجرا: **۵۸/۵۸ سبز** (زمان اجرا < ۱ ثانیه).
