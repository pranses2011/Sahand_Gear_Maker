# 📊 ماتریس قابلیت — Sahand Gear Maker نسخهٔ 0.2.0

این ماتریس «وضعیت واقعی» را نشان می‌دهد؛ حضور یک گزینه در فهرست به معنی پیاده‌سازی نیست (الزام سند ۰۴، بخش ۸).
منبع حقیقت کد: `CapabilityCatalog` (به‌روزرسانی خودکار در UI).

## خانواده‌های چرخ‌دنده (همهٔ ۱۹ خانواده پیاده‌سازی‌شده)

| خانواده | وضعیت | روش هندسی / یادداشت صادقانه |
|---|---|---|
| خارجی مستقیم (External Spur) | ✅ پیاده‌سازی‌شده و آزموده | پروفیل involute با تلرانس وتر؛ آزمون‌های واحد مستقل |
| خارجی مارپیچ (External Helical) | ✅ | برش‌های چرخیده + قدم‌زدن ادغامی؛ دقت با تلرانس وتر قابل کنترل |
| جناغی/دومارپیچ (Herringbone) | ✅ | گپ مرکزی واقعی روی برش‌ها (نه استوانهٔ جدا) |
| داخلی مستقیم/مارپیچ (Internal) | ✅ | رینگ دندانه‌دار واقعی؛ قید تداخل به‌صورت هشدار |
| شانهٔ مستقیم/مارپیچ (Rack) | ✅ | منشور دندانه‌دار با گام سازگار؛ طول پارامتر مستقل |
| مخروطی مستقیم (Straight Bevel) | ✅ | پروفیل معادل Tredgold روی مخروط پشتی؛ دندانه‌های همگرا به رأس — تقریب استاندارد مستند |
| مخروطی مارپیچ (Spiral Bevel) | ✅ | مارپیچ لگاریتمی با زاویهٔ ثابت روی مخروط بازشده |
| کرم (Worm ZA) | ✅ | سطح پیچی دقیق در مقاطع؛ ۱ تا ۱۲ رشته؛ دست چپ/راست |
| چرخ کرم (Worm Wheel) | ✅ | هلیکی هم‌دست کرم + گلوگاه گلوبوئیدی (پوشش استوانهٔ ریشهٔ کرم — روش ابزار کرم‌نما) |
| مارپیچ متقاطع (Crossed Helical) | ✅ | هندسهٔ هلیکی؛ زاویهٔ محور Σ=β₁+β₂؛ تماس نقطه‌ای (ظرفیت پایین — اعلام‌شده) |
| تاجی/پیشانی (Crown Face) | ✅ | دندانهٔ شعاعی با ارتفاع کاهشی؛ طرح‌ریزی تولید مرتبهٔ اول — پوشش Litvin حل نشده (اعلام‌شده) |
| هیپوئیدی (Hypoid) | ✅ | مخروطی مارپیچ + روابط آفست؛ حل‌گر تماس دقیق هیپوئید ندارد (اعلام‌شده) |
| سیکلوئیدی (Cycloidal) | ✅ | اپیسایکلوئید سر + هیپوسایکلوئید شعاعی ریشه (دایرهٔ مولّد نصف گام — قرارداد ساعت‌سازی) |
| غیرمدور بیضوی (Non-circular) | ✅ | حل محیط با E(e)؛ دندانهٔ شانه‌ای موضعی (تقریب مرتبهٔ اول)؛ بور روی کانون |
| فِلکسی‌پلاین هارمونیک (Harmonic) | ✅ | فنجان حالت آزاد؛ موج‌ساز بیضوی و اسپلاین دایره‌ای از مونتاژ هارمونیک |
| هزارخار خارجی/داخلی (Spline) | ✅ | اینولوت کوتاه (ha≈0.5m)؛ تلرانس واقعی جداول DIN/ISO اعمال نمی‌شود (اعلام‌شده) |

## خارج از دامنه (آگاهانه)

- محاسبهٔ استحکام/عمر/راندمان بر پایهٔ استاندارد (AGMA/ISO) — نیازمند استاندارد معتبر، آزمون مرجع و بازبینی متخصص.
- اجرای کد افزونه/اسکریپت ناشناس — سیاست امنیتی.
- تبدیل خودکار مش ورودی به چرخ‌دندهٔ پارامتریک — الگوریتم آزموده‌شدهٔ تشخیص ندارد.
